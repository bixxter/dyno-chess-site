# Dyno Chess — landing page

The marketing site for [Dyno Chess](https://bixxter.github.io/dyno-chess-site/), a
macOS app that puts a chess game in the MacBook notch.

A single self-contained `index.html`: no build step, no dependencies, no external
requests. The playable board in the hero is a real (if small) chess engine in
plain JavaScript.

The app itself lives in a separate private repository.
