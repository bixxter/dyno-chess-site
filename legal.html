The application collects nothing

This is not a promise you have to take on faith. The app is built without the com.apple.security.network.client entitlement, which means macOS itself prevents it from opening a network connection. You can verify this on your own machine before trusting a word of this page:

codesign -d --entitlements :- "Dyno Chess.app"

There is no account, no sign-in, no telemetry, no analytics and no crash reporting. Your games, move history, PGN files, settings and licence key are stored only in the app's own container on your Mac. We never receive them and have no way to.

Licence keys are verified by checking a cryptographic signature locally. Activating a licence does not contact us or anyone else.

The same command lists three permissions the app does hold, all of them local and all of them for the Claude Code integration described next: read-write access to ~/.claude and ~/.dynochess, and permission to send Apple Events to the terminal applications it can jump to. None of them can move data off your Mac; only the network entitlement could, and it is not there.

The Claude Code integration

Since version 0.3 Dyno Chess can show your Claude Code sessions in the island. This is off until you turn it on in Settings → Agents, and it works entirely between two programs on your own machine.

What it sees. When you install the integration, Claude Code runs a small helper that ships inside the app and hands it the events Claude Code publishes: the session identifier, the working directory and project name, the model, the state of the session, the last assistant message, and — for a permission request — the tool being asked for and the command or file path it names. It also reads the small per-session files Claude Code keeps in ~/.claude so that sessions started before the app was launched still appear. It never opens your conversation transcripts, and it does not read your source code.

Where it goes. Nowhere. It is held in memory to draw a row in the notch, and it is dropped when the session ends or the app quits. It is not written to a log, not saved to disk, and — the app having no network entitlement — cannot be transmitted at all. We never receive any of it.

What it writes. Only when you press Install: hook entries in ~/.claude/settings.json, after a timestamped backup of that file, appended alongside your own entries rather than replacing them. Remove takes out only the entries we added. The app also keeps a launcher, a local key and its own settings in ~/.dynochess. If the app is deleted, the launcher removes our hook entries itself.

Jumping back to the terminal. Clicking a session asks macOS to bring the right terminal forward. macOS asks for your permission the first time you do this for a given terminal application, and you can withdraw it in System Settings → Privacy & Security → Automation. We use it to raise a window and select a tab, nothing else.

The Claude Code integration

Dyno Chess can display your Claude Code sessions and, on Pro, let you approve or reject an agent's permission request from the island. Three things follow from that, and we would rather say them here than have you find them out.

  • You are responsible for what you approve. Approving from the island is exactly the same act as approving in the terminal: the agent then runs that command on your Mac. We pass your decision through and do not inspect, filter or vet what is being asked for. Approve only what you would approve in a terminal, and use Always allow only where you would.
  • It is built to fail open. If the app is not running, is quit mid-decision or errors, the integration returns no decision and Claude Code continues through its own permission flow. It cannot block your agent, and it is not a security control — it is a more convenient place to answer the same question.
  • It depends on somebody else's interface. The integration uses Claude Code's published hook interface, which Anthropic may change or withdraw at any time. We will follow such changes where we reasonably can, but continued compatibility is not something we can promise, and it is not the basis on which the licence is sold.
